BitTorrent for local LLMs

Peer-to-peer LLM inference.

Big open models run on GPUs in people's homes. BitLLM links them into one peer-to-peer network: your agent's request goes straight to someone's GPU, and the tokens stream straight back. No server in the middle, no company to switch it off.

Start in one line

Download and run. It joins the network on its own: no port forwarding, no config file.

Then open http://127.0.0.1:7778. Pick a model, copy the setup for Claude Code, Cline, Aider or any OpenAI client, and send a test message.

Share your GPU

Already running vLLM, SGLang, llama.cpp or Ollama? Point BitLLM at it and give the model its network name.

./bitllm --upstream http://localhost:8000/v1 \ --model your-name=deepseek-v4.1-flash-1017 \ --concurrency 2

Sharing makes you a contributor: no quota, and 10 invites.

How access works

Three rules. Invites are signed by an Ethereum account and gossiped like everything else, so there is no membership server.

You need an invite for a free quota

Uninvited nodes are served only when a server is idle, unless its owner opens it to everyone.

Members get a daily quota on every server

Each server owner sets it. The default is 200,000 credits a day.

Share compute and the limits go away

No quota while your nodes serve (last 7 days), and 10 invites instead of 3 once they have.

Ask a member to invite your address, then link your node to it in the dashboard. Revoking an account also removes everyone it invited.

Peer to peer, all the way

Every node runs the same program. Nodes find each other through a DHT, hear which models are online over gossip, and stream answers directly from the GPU to you. Nothing routes your requests.

Behind NAT is fine

A relay connects you first, then hole punching upgrades to a direct link when the routers allow it.

Your own model stays local

If you share a model, your gateway answers it from your own server. It never leaves your machine.

Credits for serving

Each job ends with a receipt signed by both sides and gossiped to every node. Anyone can recount the totals.

Busy servers queue you

When every server for a model is full, your request waits up to a minute for a free slot.

Models

One network name means one set of weights. Use these names when you share, or open a pull request to add one.

deepseek-v4.1-flash-1017-hereticDeepSeek V4.1 Flash, 1017 release, with refusals removed
deepseek-v4.1-flash-1017The same model, official weights

Before you use it

  • The server that answers you reads your prompt. Transport is encrypted, but the machine running the model sees the text. Don't send secrets.
  • Peers you connect to directly see your IP address. If that matters where you live, run BitLLM behind a VPN.
  • Receipts don't follow you around. Clients sign with a pseudonym per server that changes every 30 days.
  • No model verification yet. A node could serve a different model than the name it announces. Spot checks are next.
  • Credits have no value yet. The counting rules will be published before that changes.
