Get started

Use the network

Point your agent at localhost

Run the binary with no flags. It joins the network and opens an OpenAI and Anthropic compatible endpoint on your machine. Claude Code, Cline, Aider, OpenCode and anything that takes a base URL work unchanged.

./bitllm export OPENAI_BASE_URL=http://127.0.0.1:7778/v1
Share your model

Already running vLLM or llama.cpp?

Point BitLLM at your server and map its model to a network name. Peers reach you through hole punching or a relay. You choose how many requests to serve at once.

./bitllm --upstream http://localhost:8000/v1 \ --model your-name=deepseek-v4.1-flash-1017 \ --concurrency 2

How it works

Every node is the same program

There is no server that routes your requests. Nodes find each other through a Kademlia DHT, hear which models are online over gossip, and stream answers peer to peer.

Credits for servingEach job ends with a receipt signed by both sides and gossiped to every node. Anyone can recount the totals.
Busy peers queue, not failWhen every server for a model is full, your request waits up to a minute for a free slot.

How access works

  • 1. You need an invite to get a free quota. Uninvited nodes are served only when the server is idle.
  • 2. A member gets a daily free quota on each server. The server owner sets it; the default is 200,000 credits per day.
  • 3. Share compute and you're a contributor: no quota, and 10 invites instead of 3.

Invites are signed by an Ethereum account and gossiped like everything else; there is no membership server. Ask a member to invite your address, then link your node to it in the dashboard.

Before you use it

  • The peer that serves you reads your prompt. Transport is encrypted, but the machine running the model sees the text. Don't send secrets.
  • Peers you connect to directly see your IP address. If that matters where you live, run BitLLM behind a VPN.
  • Receipts don't name you. Clients sign receipts with a pseudonym per server that changes every 30 days, so the public record counts a server's distinct clients but can't follow you across servers or months.
  • No model verification yet. A node could serve a different model than the name it announces. Spot checks are next on the roadmap.
  • Credits have no value yet. The counting rules will be published before that changes. Self-dealing receipts won't count.
